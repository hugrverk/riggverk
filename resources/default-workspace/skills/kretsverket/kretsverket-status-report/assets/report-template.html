Vad återstår

Kvar att bygga

Grupperat efter när det behövs. Mycket av det som saknas är medvetna avgränsningar för den första versionen, inte buggar.

Före release

  • Signerad och notariserad macOS-app med fastställt bundle-id.
  • Paketerad smoke på macOS: öppna, spara, exportera, skriva ut och OCR i den byggda appen.
  • Verifiera sparade PDF:er från utskrift (beslutat 5 oktober).
  • Elektrikergranskning av beteckningsklasser, symbolpaket, Dellistmallar och startmall.
  • Release-ribba och versionspolicy nedskriven.

Nära efter release

  • Kablar: bättre kabelvägar och korsreferenser mellan sidor. Det blir inte en verifierad nätlista.
  • Skanning: bättre spårkvalitet och prestanda, automatisk foto- och sidkorrigering.
  • Tangentbord: mer redigering utan mus, t.ex. i Symbol Editor.
  • Fler svenska symboler och fler startmallar (laddbox, solcell, motorstart).
  • Senaste filer och mappar i skrivbordsappen.

Senare

  • Delade och team-bibliotek för symboler, med versionshantering.
  • Windows och Linux som paketerade plattformar, med uppdaterare.
  • Egen PDF-motor, bara om mätningar visar att webbläsarutskriften inte räcker.
  • Molndokument, som än så länge bara är planering.
  • Assistenten till vanliga användare, efter mätbar kvalitet.

Agentisk Kretsverket

Hur vi ligger till med Assistenten

Du skriver vad du vill ha ändrat. Assistenten tar fram ett förslag som du granskar och godkänner innan något ändras i ritningen. Hela kedjan finns och fungerar i skrivbordsappen bakom en experimentflagga.

Begäran"Granska ritning", "Fyll i metadata" eller fri text
UnderlagAktiv sida, symbolkatalog och metadata, med person- och företagsnamn maskade
ModellCodex (ChatGPT-inloggning) eller Claude API med egen nyckel
ValideringTypade operationer kontrolleras, med en reparationsrunda
FörhandsvisningSammanfattning, fynd och varje fältändring
GodkännDu väljer ändringarna själv. Inget ändras automatiskt.
Ett ångra-stegAllt som godkänns blir ett enda ångra-steg

På plats

  • ✓Ren domänkärna utan React (operationer, validering, kompilering, ångra-historik). Det gör agenten testbar utan gränssnitt.
  • ✓Två leverantörer: Codex via ChatGPT-inloggning, och Claude API med egen nyckel i macOS nyckelring, via en Rust-proxy med månadstak.
  • ✓Säkerhet: nycklar lämnar aldrig JavaScript eller .krets-filen. Förslag på inaktuell ritning stoppas.
  • ✓Golden tasks: inspelade modellsvar spelas upp i testerna, så kedjan testas utan nätverk.
  • ✓AI-läsning av text i skannade OCR-regioner med egen nyckel.
  • ✓CLI (krets) för headless DXF-export.

Inte klart

  • !Ingen mätning mot riktiga modeller. För att släppa till användare krävs minst 90 % lyckade testuppgifter, noll regelbrott och noll orelaterade ändringar. Det är inte mätt än.
  • –Bara skrivbordsappen. I webbläsaren visas bara ett meddelande.
  • –Inga bilder eller skanningar skickas till modellen (medvetet beslut för v1).
  • –Ingen AI-spårning av skannade ritningar och ingen ChatGPT-plan-väg för OCR än.
  • –MCP-server för externa agenter är planerad senare, ovanpå CLI:t.
  • –Claude-förslag är inte schemalåsta; kostnader är uppskattningar.
