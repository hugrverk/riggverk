# Security

Only the latest release is supported for security fixes.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/hugrverk/riggverk/security/advisories/new). Do not report vulnerabilities in public issues.

The scope covers the Riggverk app, the bundled workspace in `resources/default-workspace/`, and the filesystem write paths described in [the security model](docs/SECURITY_MODEL.md).

Include the app version, affected harness and version, reproduction steps, and expected impact. Do not include secrets, tokens, credentials, or private paths; redact logs and screenshots before submitting them.

First response: best effort, usually within a week.
