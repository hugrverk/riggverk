# Riggverk 2026.11.10

## New

- Imported skills get routing like the bundled ones. Import skill… has an "Add a routing line" box and a "Use when" field for each skill, filled in from the skill's own "Use when …" sentence (a "Do not use when …" sentence is skipped) and showing the exact line before it is saved. **Routing…** on an imported skill in Library, Packs adds, changes or removes its line later. The next Update adds the lines to every rules file under "Pack skill routing"; removing an imported skill takes its lines out, and Undo puts them back (#202)
- A routing file may hold up to 60 lines, and routing lines refuse hidden characters such as variation selectors, so no text reaches your agents that a diff does not show (#202)

## Fixes

- After an import, a routing change, a removal, an undo, Edit as my copy, Forget pack or saving your own pack skill, Update all is ready at once; it no longer waited for Check (#203)

## Install

Open `Riggverk-v2026.11.10-macOS.dmg`, drag Riggverk to Applications and open it from there (or unzip `Riggverk-v2026.11.10-macOS.zip` and move `Riggverk.app` to `/Applications`). One app runs on Apple silicon and Intel Macs. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk. `SHA256SUMS` lists the checksums of both downloads (`shasum -a 256 -c SHA256SUMS --ignore-missing`).
