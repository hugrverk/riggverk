# Riggverk 2026.11.2

## Changes

- The sidebar shows the rune mark next to the name (#166)
- One silver accent that matches the rune replaces the blue:
  - Update all and every primary button are silver with dark text; the light theme uses a dark graphite.
  - The ready state, focus rings, the active tab and selections follow the same accent.
  - "Yours" turns lavender so it stays apart from ready (#167)

## Install

Unzip `Riggverk-v2026.11.2-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
