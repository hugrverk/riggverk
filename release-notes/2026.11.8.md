# Riggverk 2026.11.8

## Fixes

- Scripts in skills stay runnable. A skill file that is executable where it comes from keeps its executable bit through import, Edit as my copy, install into your agents, backups and undo. The import review says so, and a change to only that bit shows in the preview (#198)
- Status labels are easier to read: every state now meets the WCAG AA contrast minimum in both light and dark mode (#197)
- After Update all, Undo and Dismiss show once, in the receipt, instead of also in the run panel (#191)

## Linux and Windows groundwork

Riggverk is being tested on Linux and Windows. These changes do not affect the Mac app (#193–#196):

- Open folder and file actions use xdg-open on Linux and Explorer on Windows.
- Agent CLIs installed through npm, bun, cargo, scoop or Linuxbrew are found.
- On Windows, a second Riggverk window cannot apply at the same time, and folders behind symlinks or junctions are refused while OneDrive folders work.
- On Linux, file names that differ only in case are kept apart, and the window has no empty strip at the top.

## Install

Open `Riggverk-v2026.11.8-macOS.dmg`, drag Riggverk to Applications and open it from there (or unzip `Riggverk-v2026.11.8-macOS.zip` and move `Riggverk.app` to `/Applications`). One app runs on Apple silicon and Intel Macs. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk. `SHA256SUMS` lists the checksums of both downloads (`shasum -a 256 -c SHA256SUMS --ignore-missing`).
