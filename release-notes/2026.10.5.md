# Riggverk 2026.10.5

## New

- Read-only security posture check and baseline guide (#84)
- Opt-in target that hides commit and PR attribution (#83)

## Install

Unzip `Riggverk-v2026.10.5-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
