# Riggverk 2026.10.4

## Fixes

- A harness Riggverk has not installed anything into shows "not installed" again, even when Riggverk already manages another harness on the same computer. Before, it showed "update available" (#80)
- The OpenCode critic in adversarial-implementation stops before the review when it would get any tool beyond reading, such as your own tools in `~/.config/opencode/tools/`, and names them so they can be denied (#81)

## Install

Unzip `Riggverk-v2026.10.4-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
