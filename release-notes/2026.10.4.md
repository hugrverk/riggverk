# Riggverk 2026.10.4

## Fixes

- Stop OpenCode critic on custom tools without _ (#81)
- Judge not installed per harness, not per profile (#80)

## Install

Unzip `Riggverk-v2026.10.4-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
