# Riggverk 2026.11.5

## Fixes

- Undo says what it does: files the update created are removed, the others come back from the backup. The confirm and the History receipt now name both (#173)
- History calls a run that only created files "Installed" (#173)
- In the update review, a new file's details say what Undo does with it, and the plan no longer reads "previewing preview" while it is computed (#173)

## Install

Unzip `Riggverk-v2026.11.5-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
