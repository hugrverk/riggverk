# Riggverk 2026.11.11

## New

- A new bundled skill, `pr-modernize`, decides first whether an old or inherited pull request should still land (modernize, rework or close), then rebases it in a throwaway worktree with hooks off, compares the series with `git range-diff`, keeps the original authors' credit and asks before any push (#224)
- `pr-workflow` can watch a pull request through CI when you ask, handing a red check to `ci-triage` and open threads to `review-response`; `review-response` keeps review fixes small and confirms each reply it posts (#217)
- The bundled troubleshooting guide explains why Claude Code shows only the names of most skills on models with a 200k context window, and the setting that shows them in full (#218)
- The skills guide says what to check before you clone a whole skill repository into `packs/`, with tstack as an example (#219)

## Fixes

- The Dock icon uses the standard macOS background in light and dark mode, like Apple's own icons (#225)
- A key pressed the moment a view opens, such as Escape on a Library item, is no longer lost (#220)
- Right after launch, before the workspace folder has been checked, the app says "Checking…" instead of calling the folder unusable, and `:update` asks you to try again (#216)
- A skill whose frontmatter is ambiguous is refused instead of guessed, and the helper scripts are hardened (#213)
- New config files, backups and saved CLI output are readable by your user only (#206)
- On Linux, a relative `XDG_CONFIG_HOME` is ignored, as the XDG specification requires (#210)

## Install

Open `Riggverk-v2026.11.11-macOS.dmg`, drag Riggverk to Applications and open it from there (or unzip `Riggverk-v2026.11.11-macOS.zip` and move `Riggverk.app` to `/Applications`). One app runs on Apple silicon and Intel Macs. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk. `SHA256SUMS` lists the checksums of both downloads (`shasum -a 256 -c SHA256SUMS --ignore-missing`).
