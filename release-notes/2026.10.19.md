# Riggverk 2026.10.19

## New

Six skills for the work around the code. Every one of them writes in your repository, commits, pushes or posts only when you ask for that step, and shows you the change first.

- `pr-workflow` turns finished work into clean commits and a pull request. It:
  - follows your repository's own conventions;
  - runs the gate before the push and writes the PR text from the diff;
  - never force-pushes (#152)
- `review-response` works through review comments on a PR. It:
  - checks each point against the code before acting, then sorts it into fix, push back with evidence, or ask;
  - drafts one reply per thread and posts only the replies you approve (#155)
- `ci-triage` reads the failed logs of a red CI run without printing secrets. It:
  - classifies the failure as code, flaky test, environment or infrastructure;
  - reproduces it locally and hands the cause to `diagnose`;
  - reruns a job only on your explicit yes (#154)
- `release-notes` drafts notes or a changelog section from the merged PRs since the last tag, in your project's own format and language (#153)
- `agents-md` creates or refreshes a repository's `AGENTS.md` from commands it has actually run, plus an optional `CLAUDE.md` pointer, so every agent shares one file (#150)
- `delegate` hands a well-specified slice to another installed agent, such as Codex, Claude Code or OpenCode, in its own git worktree. It then reviews the result like a pull request and runs every check again. It runs only when you want other agents used (#151)

## Install

Unzip `Riggverk-v2026.10.19-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
