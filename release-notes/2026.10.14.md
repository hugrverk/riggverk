# Riggverk 2026.10.14

## New

- Grok Build (xAI's `grok`) is a new light harness, off until you switch it on in Settings. It reads the skills Riggverk already installs, so it adds no new folder, and it takes your rules from the managed block in `~/.claude/CLAUDE.md` while Claude Code is on. Its page says where its rules come from. The Playwright MCP entry in `~/.grok/config.toml` is off by default; when on, it is written as one table and every other byte of the file is kept (#135)
- Google Antigravity is a new light harness, off until you switch it on in Settings. It gets the managed rules block in `~/.gemini/AGENTS.md` (`GEMINI.md` is never touched), which stays within Antigravity's 24,000-byte limit or is refused. It also gets the Playwright MCP entry in `~/.gemini/config/mcp_config.json`, off by default. Its skills go in two folders of its own, `~/.gemini/config/skills` for the app and IDE and `~/.gemini/antigravity-cli/skills` for `agy`, which are emptied of Riggverk's copies again when you switch it off (#134)

## Install

Unzip `Riggverk-v2026.10.14-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
