# Riggverk 2026.11.3

## Changes

- The `status-report` skill's HTML report uses the same silver accent as the app (#169)

## Install

Unzip `Riggverk-v2026.11.3-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
