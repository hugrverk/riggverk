# Riggverk 2026.10.12

## Fixes

- Text typed while Save and quit or Save and continue runs is no longer lost: the editor stays open and asks again (#128)
- A Library refresh that fails, or a list that no longer shows the open item, keeps your unsaved document, skill or rules draft (#128)
- A slow settings load no longer overwrites a change you just made (#128)
- An update whose every reviewed target was switched off after the preview now asks for a new preview instead of reporting an apply that never happened (#129)
- A skill can no longer take a bundled skill's name by quoting the key (`"name": tdd`) (#129)
- An update stops and leaves the file alone when a skill or agent file is edited elsewhere while the update runs (#129)
- After a crash in the middle of an update, recovery only removes or replaces a file it can prove it wrote; a file you added to since is kept as a conflict (#130)
- Undo after such a crash works even when the source changed since, and a retried rollback also restores the pack and ownership records instead of reporting success (#130)
- Undoing an earlier update keeps a pack you chose to forget after it (#130)

## Install

Unzip `Riggverk-v2026.10.12-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
