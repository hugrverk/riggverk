# Riggverk 2026.11.1

## New

- Riggverk has its own mark: a rune, as a light glyph on a dark tile, is now the app icon (#161)
- The window opens maximized the first time and then reopens where you left it, falling back to a visible display if that one is gone (#159)
- On a large window the Overview flow map grows, and agents that are off get their own dimmed rows. On a smaller window they stay grouped in one "off" node (#159)
- New skill `grill-me`, adapted from Matt Pocock's grilling skills:
  - Ask for it and it interviews you in rounds to sharpen an idea, a plan or a design, one recommendation per question.
  - It ends with a short summary of what is decided, what is open and what needs a prototype.
  - It never starts on its own and writes no files (#164)

## Fixes

From a full security audit of the app and the kit:

- **Pack skills.** For a skill from a pack, the Library and the update review now show the settings that let it act without asking, such as `allowed-tools` and `hooks` (#163)
- **Backups.**
  - Undo and crash recovery refuse a backup that is a link, owned by someone else, or writable by others.
  - OpenCode checks run from a private folder.
  - A rules file opens only inside its own folder (#163)
- **OpenCode permissions.** OpenCode now lets agents run only exact, safe forms of `git diff`, `git log`, `git show`, `tree`, `find`, the test runners and `cargo` without asking. `git add` and `git commit` ask too. Before, quoting an option could slip a command past the rules (#162)
- **Bundled skills.** They pre-approve only read-only commands. The delegate skill states plainly which routes are sandboxed. The Codex reviewer no longer reads the reviewed change's own AGENTS.md (#162)
- **Release builds.** They use the locked dependency versions. The vendored security-audit skill is checked against recorded digests (#160)

## Install

Unzip `Riggverk-v2026.11.1-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
