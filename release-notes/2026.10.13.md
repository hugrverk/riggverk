# Riggverk 2026.10.13

## Fixes

- The Library's list of personal docs no longer follows a `docs/context` folder that was replaced by a symlink, so it never reads files outside the data folder (#132)
- The Codex config merge and the OpenCode config generator run Python in isolated mode, so a `PYTHONPATH` or user site-packages can no longer slip modules into them (#132)
- The security model now states that confirmations happen in the app's own window and what keeps foreign script out of it (#132)

## Install

Unzip `Riggverk-v2026.10.13-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
