# Riggverk 2026.10.17

## New

- A skill pack can add routing lines for its own skills: a `routing.md` in the pack folder, up to 30 bullet lines that name the pack's skills. The next Update shows them in every agent's rules under "Pack skill routing", with a diff, and Undo takes them back. A line that names another skill or holds markup keeps the whole file out, and Library, Packs says which line (#142)

## Changes

- The bundled skills follow the Agent Skills format: their category, risk, targets and related skills sit under `metadata:`, each carries `license: MIT`, and skills that need subagents, Playwright, `gh` or Node say so in `compatibility`. Packs and your own skills in the older layout keep working unchanged (#143)
- NOTICE credits the projects whose methods the adversarial skills build on, and the ones that inspired others (#143)

## Install

Unzip `Riggverk-v2026.10.17-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
