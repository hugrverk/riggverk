# Riggverk 2026.11.12

## New

- Riggverk can update itself, and it asks first: nothing is requested until you turn on "Check daily" or choose Check for Updates. A new version is downloaded only after you have read what changed and pressed Download and restart, and it is installed only if it carries the release key's signature

## Fixes

- When an install updates an existing OpenCode config, the review lists every managed key it replaces in `opencode.json` and `tui.json`, with your value now and the one it becomes. An object or a list is shown only by its size and key names and an `mcp` entry never, so no credential appears in the review
- A bundled skill you made your own stays yours as a whole. When the `SKILL.md` in a skill folder is not the app's, Install leaves the folder alone and Uninstall keeps every file in it; before, Uninstall removed the files that still matched the bundled ones
- A folder at `~/.config/agent-workspace` that another tool made is left alone. Riggverk carries over an earlier data folder only when it holds Riggverk's own state folder
- The Playwright MCP entry starts `npx` from a folder the app owns, with its own `--prefix`. Started inside a repository, npm could load that repository's `.npmrc` and run programs from its `node_modules/.bin`
- A routing line for a pack or an imported skill may not contain `@`, which Claude Code reads in a rules file as "import this file"
- A pack skill with hidden or reordering Unicode characters is refused, in `SKILL.md` and in its supporting files, the same way Import skill already refused them
- The bundled skills pre-approve fewer commands for Claude Code: `gh` reads and `git config --get` with a free argument now ask first, because both can be made to print secrets
- The install review counts every file it writes or removes. A folder of subagents, a new OpenCode config, a folder of removed skill copies, the old copies in the workspace folder and a flagged pack skill each counted as one file, so the total under the plan was lower than the number of files changed
- What's new shows code and bold text in the notes as code and bold. Before, the Markdown marks were printed as they are written
- Wording corrections in 24 of the bundled skill files
- Riggverk needs macOS 13.3 or later, and the app now declares it

## Install

Open `Riggverk-v2026.11.12-macOS.dmg`, drag Riggverk to Applications and open it from there (or unzip `Riggverk-v2026.11.12-macOS.zip` and move `Riggverk.app` to `/Applications`). One app runs on Apple silicon and Intel Macs. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk. `SHA256SUMS` lists the checksums of both downloads (`shasum -a 256 -c SHA256SUMS --ignore-missing`).
