# Riggverk 2026.10.8

## Fixes

- Paths, keys and other fixed-width text use the Mac's own mono face (SF Mono) instead of a bundled font, so they match the rest of macOS and the app is smaller (#111)
- Card grids no longer end with empty slots: the last card in a short row stretches to fill it (#111)

## Install

Unzip `Riggverk-v2026.10.8-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
