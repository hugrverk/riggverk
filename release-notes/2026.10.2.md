# Riggverk 2026.10.2

## New

- adversarial-review: a fresh read-only critic finds and verifies issues and reports them without fixing anything; plan mode and a separate list for issues that were already there (#72)
- adversarial-test: an adversary writes failing tests that are then frozen, and the implementer may change only production code (#71)
- adversarial-implementation v2: the critic is chosen by capability, every finding carries a proof the lead runs, at most three rounds with frozen tests and a final round that may only delete; a start line shows who plays each role and how to change it (#69)
- Start the adversarial skills in plain words or with their slash command (#69, #71, #72)
- OpenCode: a critic model row, so the adversarial skills' critic (inspector) can run a stronger model than the other subagents (#68)

## Fixes

- Critics can no longer reach MCP tools such as Playwright, whether they run in OpenCode, Codex or Claude Code (#72)

## Install

Unzip `Riggverk-v2026.10.2-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
