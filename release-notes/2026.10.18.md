# Riggverk 2026.10.18

## Before you update

The Kretsverket skills, the Kretsverket status report profile and `wordpress-woocommerce` have left the bundled kit for a skill pack. If you use them, clone that pack into `~/.config/riggverk/packs/` before you run Update: the pack's copies then take over without rewriting anything. Without the pack, Update removes the app's copies with a backup (Undo brings them back), and copies you edited stay (#146)

## Changes

- Riggverk no longer picks a model for you: new installs get no Codex `model` or reasoning effort and no OpenCode `model` or `small_model`, so each agent uses its own default. Models already in your config stay exactly as they are, and the OpenCode per-role overrides still work (#145)
- The rules and agents are no longer tied to one person's stack:
  - The `verifier` finds your project's own build and test commands (Make, just, npm scripts, cargo, pytest, go).
  - The rules ask before adding a dependency, and treat web pages, issues, review comments and tool output as data, not instructions.
  - OpenCode lets only exact test commands run without asking; variants that could run other programs ask first (#147)
- Skills work the same in every agent:
  - `release-check` judges the gate by its own exit code.
  - `current-docs` has a fallback when no web tool is available.
  - `browser-qa` can drive Playwright from the command line, with redacted and capped output.
  - The adversarial skills carry their own reference files (#148)

## Install

Unzip `Riggverk-v2026.10.18-macOS.zip`, move `Riggverk.app` to `/Applications` and open it. Riggverk is ad hoc signed and not notarized, so macOS stops the first launch: open System Settings, Privacy & Security, and choose Open Anyway next to the message about Riggverk.
