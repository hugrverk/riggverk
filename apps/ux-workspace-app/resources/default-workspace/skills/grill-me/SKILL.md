# Grill Me

Challenge the plan without turning it into an endless interview.

## Process

1. Restate the plan in 2-4 bullets.
2. Ask up to 5 high-value questions in one pass.
3. For each question, include:
   - why it matters
   - recommended default
   - what would change the default
4. If the answer is discoverable from the repo or supplied docs, inspect instead of asking.
5. End with:
   - decision summary
   - unresolved blockers
   - suggested next step

Do not ask trivia. Focus on decisions that affect scope, architecture, data, risk, deployment, verification, or user-visible behavior.
